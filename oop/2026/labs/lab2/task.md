# Лабораторна робота №2: Графічний редактор об'єктів

## Завдання
1. Створити ієрархію класів `Shape` для представлення графічних об'єктів.
2. Реалізувати базовий абстрактний клас `Shape` та похідні класи: `PointShape`, `LineShape`, `RectShape`, `EllipseShape`.
3. Створити головне вікно редактора з можливістю малювання об'єктів за допомогою миші.
4. Реалізувати ефект «гумової стрічки» (rubber-band) під час малювання.
5. Додати меню для вибору типу об'єкта.

## Варіант (Ж = 7)
- Масив об'єктів: `7 mod 3 = 1`
- Слід (rubber-band): `7 mod 4 = 3`
- Кольори та ввід: за формулами `Ж mod 2/5/6`
